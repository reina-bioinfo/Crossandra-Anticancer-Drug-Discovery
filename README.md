# Biomolecular Characterization of Crossandra infundibuliformis and In Silico Evaluation of Anticancer Activity

## Overview

This project investigates the phytochemical composition of *Crossandra infundibuliformis* flowers and evaluates their potential anticancer activity using computational molecular docking approaches.

The study combines:

- Preliminary phytochemical screening
- GC-MS compound identification
- Ligand selection
- Molecular docking using PyRx
- Binding affinity analysis

## Objectives

- Identify phytochemical compounds present in *Crossandra infundibuliformis*
- Analyze GC-MS identified compounds
- Evaluate anticancer potential through molecular docking
- Identify compounds with favorable binding affinity
